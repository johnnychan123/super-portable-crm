# Super Portable CRM — 外部匯出 Excel 篩選匯入、多次比對選取與彈性欄位匯出設計文件

- **日期**：2026-10-31
- **狀態**：待審核 (Draft)

---

## 1. 背景與目標 (Intent & Why)

在舉辦大型活動時，工作人員常需要以「過去活動匯出並整理過的 Excel 名單」作為本次活動名單的篩選與勾選依據。然而，過去匯出的 Excel 往往經過人工增刪欄位（例如刪除了不重要的內部欄位，或新增了「桌號」、「車牌」、「餐點備註」等該次活動專屬欄位），其欄位結構不會與主 `DB` 的 50 個欄位完全一致。

本功能的目標是：
1. 提供獨立於「匯入主 DB」之外的**「匯入篩選 Excel」**新操作，且**支援多次匯入**多個過去的 Excel 檔案。
2. 即使篩選 Excel 的欄位經過刪減或新增，仍能自動（或手動指定欄位）與主 `DB` 名單進行精準比對。
3. 匯入時預設先不自動改動目前已勾選狀態，讓使用者可針對每個已匯入的篩選 Excel 檢視命中結果，並一鍵執行**「勾選此檔命中名單」**、**「取消勾選」**或**「設為表格篩選條件」**。
4. 匯出本次 Excel 時，除了維持原本「完整 50 欄」外，也允許使用者**按需選擇匯出欄位**（例如直接沿用某個已匯入篩選 Excel 的欄位結構，或自訂勾選要保留的 DB 欄位與新增活動專屬欄位），並可選擇額外欄位要「留空供本次填寫（預設）」或「帶入舊檔對應資料」。

---

## 2. 目標與非目標 (Goals, Non-Goals & Anti-Goals)

### 目標 (Goals)
- **支援多次匯入外部篩選 Excel**：可陸續匯入 1 至多個 `.xlsx` / `.xls` 檔案並保留在「已匯入篩選 Excel 清單」中，各自獨立統計命中筆數。
- **跨結構智慧人員比對**：
  - 自動偵測主 `DB` 與外部篩選檔之間的共同識別欄（優先順序：`Pf.ID` → `PID + 組別` → `PID` → `組別 + 姓名` → `姓名` → `中文名(沒有稱謂)` → 第一個有效共同欄位）。
  - 支援使用者在每個篩選檔卡片上手動切換比對欄位（例如改用 `姓名`、`組別 + 姓名` 或任意共同欄位），切換後即時重新計算命中結果。
- **可控的選取與篩選連動**：
  - 匯入當下**預設不自動勾選**，由使用者點擊「勾選此檔命中名單 (N)」才將命中列加入 `selectedRowNumbers`；亦可一鍵「取消勾選此檔命中名單」。
  - 支援將外部篩選檔作為表格過濾條件：可選擇「全部顯示」、「任一篩選檔命中（聯集）」、「全部篩選檔皆命中（交集）」或「指定單一篩選檔命中」。
- **按需選擇匯出欄位與額外欄位處理**：
  - 匯出欄位模式支援：
    1. **主 DB 完整欄位（預設 50 欄）**
    2. **沿用指定篩選 Excel 的欄位配置**（自動套用該檔留存的 DB 欄位與新增的活動欄位順序）
    3. **自訂勾選匯出欄位**（自由勾選/取消 DB 欄位，並可新增/移除本次活動需要的額外空白欄位）
  - 當匯出包含非主 DB 原有的「活動專屬額外欄位」時，**預設只輸出空白欄位標題**（方便本次活動重新填寫），並提供開關讓使用者可選擇**「帶入舊篩選檔該欄資料」**。

### 非目標 (Non-Goals)
- 不直接修改主 `DB` 原始載入的欄位值。
- 不強制要求匯入的篩選 Excel 必須包含 `組別` 或 `界別` 工作表（只要第一張工作表或 `DB` 工作表有標題列與人員資料即可比對）。

### 反目標 (Anti-Goals)
- **不可因外部 Excel 缺少部分 DB 欄位而拒絕匯入**：只要有至少一個可用於比對的共同欄位即可運作。
- **不可在匯入篩選檔時未經同意覆蓋或清空使用者原本已勾選的名單**。

## 3. 評估方案與選擇 (Approaches)

1. **方案 A（已選擇）：在 DB 主名單上方提供整合式「匯入篩選 Excel」與「匯出欄位設定」抽屜面板**
   - **做法**：在 DB 主名單工具列（與「自訂欄位條件」並列）提供「匯入篩選 Excel」與「匯出欄位設定」按鈕及可展開面板，使用者可邊操作篩選檔卡片（勾選命中、切換比對欄、過濾檢視）邊在下方虛擬表格即時查看名單變化。
   - **優點**：操作路徑最短，視覺回饋即時，不需離開主名單畫面。
2. **方案 B：新增獨立的第 4 個 Tab 分頁管理外部篩選檔与匯出欄位**
   - **捨棄原因**：在勾選與確認名單時需頻繁在 Tab 間來回切換，無法即時對照主表格內容。

## 4. 詳細設計規格 (Detailed Specification)

### 4.1 外部篩選 Excel 解析與比對模組 (`src/lib/externalFilterMatcher.ts`)

1. **解析外部篩選 Excel (`parseExternalFilterWorkbook`)**：
   - 支援讀取任意 `.xlsx` / `.xls` 檔案。優先讀取名為 `DB` 的工作表，若無則讀取第一張工作表 (`workbook.SheetNames[0]`)。
   - 提取第 1 列為 `headers: string[]`（正規化 `_x000D_` 與空白）。
   - 掃描資料列，自動略過全空列與分組標題列（例如 `姓名` 符合 `SECTION_CODE_REGEX` 且無其他有效人員識別值之列），產生 `rows: Record<string, string>[]`。
   - 比對主 `workbook.dbHeaders`，分類出：
     - `sharedHeaders: string[]`：同時存在於主 `DB` 與該篩選 Excel 的欄位。
     - `extraHeaders: string[]`：僅存在於該篩選 Excel、不在主 `DB` 內的活動專屬欄位。

2. **比對策略 (`ExternalMatchStrategy` & `matchExternalFilterToDb`)**：
   - 支援的比對鍵模式 (`matchKey`)：
     - `'auto'`（預設）：依優先序 `[ ['Pf.ID'], ['PID', '組別'], ['PID'], ['組別', '姓名'], ['姓名'], ['中文名(沒有稱謂)'] ]` 檢查哪些欄位同時存在於 `sharedHeaders` 且在外部檔與主 DB 中皆有非空值；若皆無則退回第一個非空的共同欄位。
     - 複合鍵：`'PID+組別'`、`'組別+姓名'`。
     - 單一共同欄位：任意屬於 `sharedHeaders` 的欄位名稱（如 `'Pf.ID'`、`'PID'`、`'姓名'`、`'中文名(沒有稱謂)'`、`'電話'` 等）。
   - 比對正規化：比對字串時自動 `trim()` 並忽略大小寫差異；空白值不參與碰撞（避免兩個空白儲存格誤判為同一人）。
   - 比對結果 (`ExternalFilterMatchResult`)：
     - `resolvedKeyColumns: string[]`：實際使用的比對欄位名稱（供 UI 顯示，例如 `自動 (組別 + 姓名)`）。
     - `matchedDbRowNumbers: Set<number>`：命中的主 `DB` 記錄列號集合。
     - `matchedExternalRowCount: number`：外部篩選檔中有成功對應到主 `DB` 的列數。
     - `unmatchedExternalRowCount: number`：外部篩選檔中未能對應到主 `DB` 的列數。
     - `extraValuesByDbRow: Map<number, Record<string, string>>`：記錄每筆命中的主 `DB` `rowNumber` 在外部檔中對應的 `extraHeaders` 欄位值（供匯出時若勾選「帶入舊檔該欄資料」使用）。

### 4.2 多次匯入篩選 Excel 的狀態與互動 (`src/App.tsx` & `src/lib/excelParser.ts`)

1. **支援一次或分批多次匯入**：
   - Electron 端與瀏覽器 `<input type="file" multiple>` 支援選取單一或多個 `.xlsx/.xls` 作為篩選檔，並可不限次數重複點擊「+ 匯入篩選 Excel」累加至 `importedFilterFiles` 清單。
   - 匯入完成時**不自動修改 `selectedRowNumbers`**，而是展開「外部篩選 Excel」面板並顯示新匯入的檔案卡片與命中統計提示。

2. **單一篩選檔卡片操作**：
   - 顯示檔名、總列數、命中主 DB 筆數（如 `命中 32 筆 / 外部檔 35 列`）、共用欄位數與額外欄位數。
   - **比對欄位選擇器**：下拉選單可切換 `自動偵測`、`組別 + 姓名`、`PID + 組別` 或任意共同欄位。
   - **選取動作按鈕**：
     - `勾選此檔命中 (N)`：將該檔 `matchedDbRowNumbers` 加入 `selectedRowNumbers`（並顯示目前已勾選其中幾筆）。
     - `取消勾選此檔`：從 `selectedRowNumbers` 移除該檔 `matchedDbRowNumbers`。
   - **篩選檢視按鈕**：
     - `僅顯示此檔名單`：切換表格的 `externalFilterMode` 為該檔案 ID，讓主表格只顯示該檔命中的人員。
   - **匯出欄位套用按鈕**：
     - `套用此檔欄位結構`：一鍵將匯出欄位設定切換為沿用此篩選檔的欄位（含其保留的 DB 欄位與額外活動欄位）。
   - **移除按鈕**：從清單中移除此篩選檔。

3. **多檔組合操作**：
   - 當匯入多個篩選 Excel 時，面板頂部提供：
     - `勾選全部篩選檔命中 (聯集)` / `取消勾選全部篩選檔`
     - 篩選模式切換：`不限 (全部顯示)`、`任一篩選檔命中 (聯集)`、`所有篩選檔皆命中 (交集)`、或指定單一篩選檔。
   - `filterDbRows` 新增 `externalMatchedRowNumbers?: ReadonlySet<number>` 支援，與既有的界別、組別、出席狀態、關鍵字與自訂條件無縫組合（AND 交集過濾）。

### 4.3 彈性匯出欄位設定 (`src/lib/excelExporter.ts`)

擴充 `ExportCrmOptions`：

```ts
export interface ExportCrmOptions {
  targetRecordRowNumbers: ReadonlySet<number>;
  /** 若指定則依此欄位順序輸出 DB 工作表；未指定則輸出完整 workbook.dbHeaders (50 欄) */
  outputHeaders?: string[];
  /** 是否在匯出非 DB 原有欄位時，帶入外部篩選檔對應人員的舊資料（預設 false 留空） */
  populateExtraColumnValues?: boolean;
  /** 外部篩選檔對應的額外欄位資料 (rowNumber -> { extraHeader: value }) */
  extraValuesByRowNumber?: ReadonlyMap<number, Record<string, string>>;
}
```

- **匯出欄位設定面板（按需選擇）**：
  1. **模式一：主 DB 完整欄位（預設，50 欄）**
  2. **模式二：沿用已匯入篩選 Excel 的欄位**：選擇任一已匯入的篩選檔，直接採用該檔的 `headers` 順序（自動顯示包含幾個 DB 欄位、幾個活動專屬額外欄位）。
  3. **模式三：自訂勾選與新增欄位**：
     - 可從主 DB 50 欄中自由勾選/取消要匯出的欄位（支援一鍵「套用目前檢視預設集：核心/聯絡/個人/全選」或「從已匯入篩選檔載入」作為起點再微調）。
     - 可輸入新增本次活動需要的自訂欄位名稱（如 `簽到`、`桌號`、`車牌`），附加於匯出欄位中。
  - **額外欄位內容開關**：
    - 當匯出欄位包含非 DB 原有欄位時，顯示勾選開關：`帶入舊篩選檔中對應人員的額外欄位資料`（**預設不勾選**，即只保留欄位標題、內容留空供本次活動填寫；勾選時則填入比對命中的舊檔資料）。
- **分組標題列 (`kind === 'section'`) 相容處理**：
  - 若自訂匯出欄位中包含 `姓名`，分組標題列依然寫入 `姓名` 欄（若下一欄為 `職位` 則自動建立合併儲存格）。
  - 若使用者在自訂匯出欄位中取消了 `姓名` 欄，分組標題列的標題文字會自動回退寫入第 1 個匯出欄位，確保分組標題列在精簡欄位匯出時依然清晰可見。
